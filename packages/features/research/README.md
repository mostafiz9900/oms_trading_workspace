# Research package

Shared issuer research DTOs for OMS broker-house apps: company profile and
financial metrics, dividends, EPS, and issuer news. Existing JSON keys,
parsing, and model shapes are preserved.

The Benemoy app keeps compatibility exports at the previous model paths. Data
fetching, caching, controllers, and research UI remain app-owned.

```dart
import 'package:research/research.dart';
```
