# Benemoy brand manifest

This manifest documents the current Benemoy brand paths, default locale,
colors, support/document links, and client capability catalog. Runtime app
branding is read from the UAT/production Dart define profiles through
`broker_config`; the manifest's capability flags are documentation only and
do not authorize trading actions.

The current Flutter logos live in `assets/svg_image/`. Launcher icons remain
native Android/iOS assets. New house-specific Flutter artwork belongs under
`assets/houses/<house_id>/` and should use the matching `OMS_BRAND_*_ASSET`
defines generated by the Mason `house_profile` brick.
